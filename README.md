# 🏆 Quiz-Master

A responsive quiz application built using HTML, CSS and JavaScript, featuring multiple-choice questions, a timer, score tracking and an interactive user interface.

## 🚀 Features

- 📝 Multiple-choice questions
- ⏱️ Timer for each question
- 📊 Score tracking
- ✅ Instant correct/incorrect feedback
- 🔄 Restart quiz functionality
- 📱 Responsive design
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- GitHub Pages
